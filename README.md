# Test Repository

A small repository containing exploratory files. It currently includes `HelloWorld.java` and a text document.

## Purpose

This repository is a minimal experiment, not a released application or a supported API. No build automation, dependency management, CI workflow, or production deployment is established here.

## Basic Java example

If a JDK is installed, inspect `HelloWorld.java` and its declared class and package before compiling. A typical standalone Java source file can be compiled with:

```bash
javac HelloWorld.java
```

Run the generated class using its actual declared class name. This README does not assume a fixed entry-point name beyond what is present in the source.

## Contribution rules

Keep new documentation, commit messages, code comments, issues, and PR descriptions in English. Do not overwrite historical experimental files without reviewing their contents.
